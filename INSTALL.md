# Install Music

Copy music files to `/mnt/us/music` (or to `/mnt/us/music/library`) on the Kindle's user storage. Supported formats:
MP3, FLAC, Ogg Vorbis, WAV, M4A and AAC.

Connect headphones in Settings › Bluetooth, then open Music from the library or the launcher. Tap a track to play it.
Exit returns to the launcher.
